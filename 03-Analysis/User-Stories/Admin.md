# Hagz — Admin User Stories

## Epic: Court Moderation

### US-ADM-001

**As an administrator, I want to view submitted courts so that I can review them before they become publicly available.**

### US-ADM-002

**As an administrator, I want to review court information so that I can make an informed moderation decision.**

### US-ADM-003

**As an administrator, I want to approve a court so that it can become available to players.**

### US-ADM-004

**As an administrator, I want to reject a court so that invalid or unacceptable submissions are not publicly listed.**

---

## Epic: User Management

### US-ADM-005

**As an administrator, I want to view platform users so that I can manage user accounts.**

### US-ADM-006

**As an administrator, I want to manage user accounts so that the platform remains properly controlled.**
