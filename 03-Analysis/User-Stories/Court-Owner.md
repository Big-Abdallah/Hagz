# Hagz — Court Owner User Stories

## Epic: Court Management

### US-OWN-001

**As a court owner, I want to create an account so that I can manage my courts on Hagz.**

### US-OWN-002

**As a court owner, I want to add a court so that players can discover it after approval.**

### US-OWN-003

**As a court owner, I want to update my court information so that players see accurate information.**

### US-OWN-004

**As a court owner, I want to upload court photos so that players can visually evaluate the court.**

### US-OWN-005

**As a court owner, I want to set the court price so that players know the booking cost.**

---

## Epic: Availability

### US-OWN-006

**As a court owner, I want to define available time slots so that players can book the court when it is available.**

### US-OWN-007

**As a court owner, I want to manage court availability so that unavailable periods are not offered for booking.**

---

## Epic: Booking Management

### US-OWN-008

**As a court owner, I want to view incoming booking requests so that I can manage reservations for my courts.**

### US-OWN-009

**As a court owner, I want to accept booking requests so that valid reservations can be confirmed.**

### US-OWN-010

**As a court owner, I want to reject booking requests so that I can decline reservations that cannot be fulfilled.**
