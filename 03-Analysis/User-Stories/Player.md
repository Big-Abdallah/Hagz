# Hagz — Player User Stories

## Epic: Player Account

### US-PLY-001

**As a player, I want to create an account so that I can use the booking features of Hagz.**

### US-PLY-002

**As a player, I want to log in so that I can securely access my account.**

---

## Epic: Court Discovery

### US-PLY-003

**As a player, I want to search for courts so that I can find a suitable place to play.**

### US-PLY-004

**As a player, I want to filter courts by area so that I can find courts near my preferred location.**

### US-PLY-005

**As a player, I want to filter courts by price so that I can find courts within my budget.**

### US-PLY-006

**As a player, I want to view court details so that I can decide whether the court is suitable for me.**

### US-PLY-007

**As a player, I want to view available time slots so that I can choose a suitable time.**

---

## Epic: Booking

### US-PLY-008

**As a player, I want to book an available time slot so that I can reserve the court.**

### US-PLY-009

**As a player, I want to cancel an eligible booking so that I can release a reservation I no longer need.**

### US-PLY-010

**As a player, I want to view my bookings so that I can keep track of my reservations.**
