# Hagz — Project Overview

## 1. Project Name

**Hagz**

## 2. Project Type

Full-Stack Web Application for Sports Court Booking and Management.

## 3. Project Description

Hagz is a sports court booking platform designed to connect players with sports court owners through a simple and organized digital booking system.

The platform allows players to discover available courts, view their information and prices, check available time slots, and make bookings.

Court owners can manage their courts, define available time slots, and handle incoming booking requests.

An administrator manages the platform by reviewing newly submitted courts and controlling the approval process.

## 4. Main Goal

The main goal of Hagz is to simplify the process of finding and booking sports courts while providing court owners with an organized way to manage their courts and bookings.

## 5. Target Users

The system is designed for three main types of users:

* **Player**
* **Court Owner**
* **Administrator**

## 6. Core System Features

### Player

* Register and log in.
* Search for courts by area and price.
* View court information.
* View available time slots.
* Book an available time slot.
* Cancel a booking.
* View current and previous bookings.

### Court Owner

* Register and log in.
* Add a sports court.
* Provide court information such as:

  * Court name
  * Address
  * Price
  * Photos
* Define available time slots.
* Receive booking requests.
* Accept or reject booking requests.
* Manage court information.

### Administrator

* Review newly submitted courts.
* Approve or reject courts.
* Manage platform users.
* Monitor the overall platform.

## 7. Project Scope

The first version of Hagz focuses on the essential booking workflow between players and court owners.

The system does not initially focus on advanced features such as online payments, subscriptions, advertisements, or complex recommendation systems.

These features may be considered for future versions.

## 8. Expected Outcome

The expected outcome is a functional full-stack application that demonstrates the complete software engineering lifecycle, including:

* Requirements analysis
* System analysis
* System design
* Database design
* API development
* Frontend development
* Testing
* Deployment
