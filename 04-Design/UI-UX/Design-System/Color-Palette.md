# Hagz — Color Palette

## 1. Primary Colors

### Deep Navy

```text
#0B1220
```

Usage:

* Primary backgrounds.
* Navigation.
* Headers.
* Primary text on light backgrounds.
* Brand elements.
* Logo.

---

### Lime

```text
#B6F03C
```

Usage:

* Primary accent.
* Calls to action.
* Active states.
* Important highlights.
* Selected elements.
* Brand accent.

Lime should be used selectively rather than covering large areas of the interface.

---

## 2. Neutral Colors

### White

```text
#FFFFFF
```

Usage:

* Cards.
* Content areas.
* Forms.
* Primary surfaces.

### Light Gray

```text
#E5E7EB
```

Usage:

* Borders.
* Dividers.
* Input outlines.
* Secondary UI elements.

---

## 3. Color Principle

The Hagz interface should primarily use:

```text
Deep Navy
     +
White
     +
Light Gray
     +
Selective Lime
```

No additional brand colors should be introduced without a documented design reason.

---

## 4. Semantic Colors

Semantic colors may be introduced where necessary for system feedback.

Examples:

* Success
* Warning
* Error
* Informational

These should be used only for communicating system states and should not become additional brand colors.
