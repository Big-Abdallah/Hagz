# Hagz — Logo Guidelines

## 1. Logo Concept

The Hagz logo is based on a custom geometric **H monogram**.

The symbol does not directly represent a football, pitch, goal, location pin, calendar, or generic booking icon.

Instead, the geometry represents:

```text
Two paths
    ↓
Choice
    ↓
Intersection
    ↓
Connection
    ↓
Booking
```

This concept reflects the core function of Hagz: connecting players with available sports courts.

---

## 2. Visual Language

The logo uses:

* Geometric shapes.
* Clean intersections.
* Negative space.
* Strong directional forms.
* Controlled asymmetry where appropriate.

The design should feel engineered rather than decorative.

---

## 3. Color Usage

Primary logo color:

```text
Deep Navy
#0B1220
```

Accent:

```text
Lime
#B6F03C
```

Lime should appear as a controlled visual accent or in negative-space elements.

---

## 4. Logo Restrictions

Do not:

* Add football graphics.
* Add a football field.
* Add a location pin.
* Add a calendar.
* Add a generic checkmark.
* Add gradients.
* Add unnecessary shadows.
* Distort the proportions.
* Add unrelated decorative elements.

---

## 5. Usage

The logo should work in:

* Website header.
* Favicon.
* Mobile application icon.
* Social media profile.
* Presentation.
* Documentation.
* Marketing materials.

The symbol should remain recognizable even at small sizes.
