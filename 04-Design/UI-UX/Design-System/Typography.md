# Hagz — Typography

## 1. Primary Typeface

### Poppins

Poppins is the primary typeface for English interface content.

It is used for:

* Headings.
* Buttons.
* Navigation.
* Body text.
* Form labels.
* UI components.

---

## 2. Arabic Typeface

### Cairo

Cairo is used for Arabic interface content.

It provides good readability and maintains consistency with the modern visual identity of Hagz.

---

## 3. Typography Hierarchy

The interface should use a clear hierarchy.

### Display

Used for major page headings.

### Heading

Used for section and component titles.

### Body

Used for general information.

### Caption

Used for secondary information.

### Label

Used for forms and compact UI elements.

---

## 4. Typography Principles

* Avoid excessive font weights.
* Maintain consistent hierarchy.
* Use sufficient line height.
* Do not use typography as decoration.
* Prioritize readability over visual complexity.

---

## 5. Language Support

Hagz should support both:

* English.
* Arabic.

Arabic layouts should use RTL direction where appropriate.
